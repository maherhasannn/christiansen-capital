# Christiansen Capital — Website

Source for [www.christiansencapital.com](https://www.christiansencapital.com), the marketing site for **Christiansen Capital**, a private direct hard-money lender headquartered in Murrieta, California that serves real estate investors across the state.

## What's here

A single-page static site hosted on GitHub Pages:

- `index.html` — the whole site: hero, loan programs (fixer-upper financing, rental property loans, new construction loans, bridge loans), about/trust section, image gallery, customer testimonials, fine print, and contact.
- `css/` — `style.css` and `namari-color.css` for the theme, plus vendored `animate.css` and Font Awesome.
- `js/` — jQuery and the plugins the page uses (Featherlight gallery/lightbox, WOW scroll animations, sticky navbar, waypoints, parallax); site-specific behavior is in `site.js`.
- `images/` — logos, banner, gallery photos, and testimonial headshots.
- `fonts/` — Font Awesome webfonts.
- `CNAME` — custom domain for GitHub Pages.

## Editing

No build step. Edit `index.html` (or the CSS/JS) and push to `main`; GitHub Pages redeploys automatically.

## Credits

Built on the Namari one-page template.
